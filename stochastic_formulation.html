Side-by-Side Comparison
Column Generation — Deterministic (current)

Objective:

$$\min \sum_{i} c_i\, x_i \;+\; \sum_{m} f_m\, z_m \;+\; (C_{\mathrm{mat}}+C_{\mathrm{qc}})|P|$$

Variables:

  • \(z_m \in \{0,1\}\) — open facility
  • \(x_i \in \{0,1\}\) — select plan \(i\) for patient \(p(i)\)
  • Plan \(i\) = \((m,\, j_{\mathrm{out}},\, j_{\mathrm{ret}},\, w{=}0)\)
  • \(\mathrm{TRT}_i = T_{\mathrm{LS}} + \mathrm{TT}^o_{j_{\mathrm{out}}} + T_{\mathrm{MF}} + T_{\mathrm{QC}} + \mathrm{TT}^r_{j_{\mathrm{ret}}}\)  (fixed)

Key Constraints:

  • \(\displaystyle\sum_{i\,\in\,\mathrm{Plans}_p} x_i = 1\)  — one plan per patient
  • \(x_i \le z_{m(i)}\)  — plan uses open facility
  • \(\displaystyle\sum_m z_m \le 2\)  — at most 2 facilities
  • Capacity: \(\mathrm{entering}(m,t) - \mathrm{leaving}(m,t) \le \mathrm{FCAP}_m - \mathrm{recent}(m,t)\)
  • Hard deadline at plan generation: if \(\mathrm{TRT}_i > D_p\), plan \(i\) is never created
  • Wait \(w = 0\) always (MSB1 constraint in MIP)
Size: \(O(|P|\cdot|M|\cdot|J|^2)\approx 258\) plans for \(N{=}15\)
Deadline enforced by filtering — infeasible plans excluded at generation
Column Generation — Stochastic SAA (proposed)

Objective:

$$\min \underbrace{\sum_{r} c_r\, x_r + \sum_{m} f_m\, z_m + (C_{\mathrm{mat}}+C_{\mathrm{qc}})|P|}_{\text{Stage 1: route cost}} + \underbrace{\frac{1}{S}\sum_{\omega}\sum_{p} B\cdot L^{\omega}_p}_{\text{Stage 2: expected lateness}}$$

Variables:

  • S1 \(z_m \in \{0,1\}\) — open facility
  • S1 \(x_r \in \{0,1\}\) — select route \(r\) for patient \(p(r)\)
  • S1 Route \(r\) = \((m,\, j_{\mathrm{out}},\, j_{\mathrm{ret}})\) — no wait, no TRT
  • S2 \(W^{\omega}_p \ge 0\) — wait recourse per scenario NEW
  • S2 \(L^{\omega}_p \ge 0\) — lateness per scenario NEW

Stage 1 Constraints (scenario-independent):

  • \(\displaystyle\sum_{r\,\in\,\mathrm{Routes}_p} x_r = 1\;\;\forall p\)  — one route per patient
  • \(x_r \le z_{m(r)}\;\;\forall r\)  — route uses open facility
  • \(\displaystyle\sum_m z_m \le 2\)

Stage 2 Constraints \(\forall\,\omega \in \Omega,\; \forall\, p \in P\):

  • Deadline: \(\;\displaystyle\sum_r \!\bigl(T_{\mathrm{LS}} + \mathrm{TT}^o_{j_{\mathrm{out}}(r)} + T^{\omega}_{\mathrm{MF}} + T_{\mathrm{QC}} + \mathrm{TT}^r_{j_{\mathrm{ret}}(r)}\bigr)x_r + W^{\omega}_p \le D_p + L^{\omega}_p\)
  • Capacity \(\forall m,t\): concurrent patients at \(m\) in \([t, t{+}T^{\omega}_{\mathrm{MF}})\) \(\le \mathrm{FCAP}_m\) SCENARIO-DEPENDENT
  • \(W^{\omega}_p \ge 0,\;\; L^{\omega}_p \ge 0\)
Stage 1: \(O(|P|\cdot|M|\cdot|J|^2)\approx 258\) routes for \(N{=}15\) (same as before)
Stage 2: \(S \times |P|\) new recourse variables — subproblems solved by CP-SAT per scenario
All routes kept — no deadline filtering at generation; infeasibility absorbed by \(L^{\omega}_p\)
Why routes replace plans: In the deterministic colgen, a “plan” embeds a fixed TRT because wait \(w=0\) and \(T_{\mathrm{MF}}\) is constant — so deadline feasibility is checked at generation and infeasible plans are discarded. Under SAA, \(T^{\omega}_{\mathrm{MF}}\) differs per scenario, so no single TRT exists at generation time. The column becomes a route \((m, j_{\mathrm{out}}, j_{\mathrm{ret}})\) with no timing commitment. The wait \(W^{\omega}_p\) is now a recourse variable decided after \(T^{\omega}_{\mathrm{MF}}\) is realised, solving the staggering problem per scenario via CP-SAT.

Scenario Design — TMF Distribution
Scenario A — Nominal

Manufacturing completes in 7 days (standard process, no QC hold).

Probability: 0.60

Scenario B — Extended

Minor QC hold or low cell yield requires 10 days of manufacturing.

Probability: 0.30

Scenario C — Delayed

Batch failure / restart: manufacturing requires 14 days total.

Probability: 0.10

In SAA, each of the S sampled scenarios draws TωMF independently from this mixture. For tractability, S = 10–30 scenarios is typically sufficient. The subproblems for each ω are independent and run in parallel.

Solution Algorithm — L-Shaped Method (Stochastic Benders)
0
Initialise: Generate all routes \(\{r\} = \{(m, j_{\mathrm{out}}, j_{\mathrm{ret}})\}\). Sample \(S\) scenarios \(\{T^{\omega}_{\mathrm{MF}}\}\). Set \(\theta = 0\), iteration \(k = 0\).
1
Solve Master IP: Select routes \(x^*_r \in \{0,1\}\) and facilities \(z^*_m\) minimising Stage 1 cost \(+ \theta\). (HiGHS MIP, same structure as current solve_master() minus capacity constraints.)
2
Solve S Subproblems in parallel: For each \(\omega \in \Omega\), run CP-SAT with routes fixed to \(x^*\) and duration \(T^{\omega}_{\mathrm{MF}}\). CP-SAT finds optimal wait times \(W^{\omega}_p\) and lateness \(L^{\omega}_p\). Returns \(Q^{\omega}(x^*) = B\sum_p L^{\omega}_p\).
3
Check convergence: Compute \(\hat{Q} = \frac{1}{S}\sum_{\omega}Q^{\omega}(x^*)\). If \(\hat{Q} \le \theta + \varepsilon\), STOP — optimal solution found.
4
Add optimality cut to master: For each \(\omega\) where \(Q^{\omega}(x^*) > 0\), identify conflicting patient-facility assignments and add Benders cut constraining route selection. Set \(\theta \leftarrow \hat{Q}\), \(k \leftarrow k{+}1\), go to Step 1.
Why the plan-generation concern disappears: In the deterministic colgen, deadlines are enforced by excluding plans with TRT > D_p at generation — so if TMFE shifts, some plans would have been wrongly included or excluded. In the SAA formulation, routes carry no TRT. The deadline is evaluated inside each scenario’s CP-SAT subproblem with the realised \(T^{\omega}_{\mathrm{MF}}\). A route that is risky under long-\(T_{\mathrm{MF}}\) scenarios will accumulate expected lateness penalty and be naturally de-selected by the master — not artificially removed. This is stochasticity working correctly.
