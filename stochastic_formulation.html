CAR-T Cell Therapy Supply Chain Optimization

Deterministic Column Generation vs. Two-Stage Stochastic (Expediting Recourse) — Manufacturing Time Uncertainty

Problem: Minimize total cost (facility + transport + expected expediting) subject to patient deadlines under uncertain manufacturing time \(T_{\mathrm{MF}}\).
Uncertainty: \(T_{\mathrm{MF}} \sim \mathrm{LogNormal}(\mu_L,\,\sigma_L^2)\) with nominal mean \(\mathbb{E}[T_{\mathrm{MF}}] = 7\) days  |  Stage-2 Recourse: If \(T_{\mathrm{MF}} > K_i\), expedite the return shipment: pay premium \(\pi_p\), save \(\delta\) days  |  No penalty terms. Hard deadlines enforced via plan filter.

Side-by-Side Comparison
Column Generation — Deterministic

Objective:

$$\min \sum_{m} f_m\, z_m \;+\; \sum_{i} c_i\, x_i \;+\; C_{\mathrm{fixed}}|P|$$

where \(c_i = U^o_{c,m,j_{\mathrm{out}}} + U^r_{m,h,j_{\mathrm{ret}}}\)

Plan structure:

  • Plan \(i = (m,\, j_{\mathrm{out}},\, j_{\mathrm{ret}},\, w{=}0)\)
  • \(\mathrm{TRT}_i = T_{\mathrm{LS}} + \mathrm{TT}^o_{j_{\mathrm{out}}} + T_{\mathrm{MF}} + T_{\mathrm{QC}} + \mathrm{TT}^r_{j_{\mathrm{ret}}}\)
  • Filter: plan \(i\) excluded if \(\mathrm{TRT}_i > D_p\)

Key Constraints:

  • \(\displaystyle\sum_{i\,\in\,\mathrm{Plans}_p} x_i = 1\;\;\forall p\)
  • \(x_i \le z_{m(i)}\;\;\forall i\)
  • \(\displaystyle\sum_m z_m \le 2\)
  • Capacity: concurrent patients at \(m\) during \(T_{\mathrm{MF}}\) \(\le \mathrm{FCAP}_m\)
Plan count: \(O(|P|\cdot|M|\cdot|J|^2)\). Deadline enforced by filtering — infeasible plans excluded at generation.
Column Generation — Two-Stage Stochastic (Expediting)

Objective:

$$\min \sum_{m} f_m\, z_m \;+\; \sum_{i} \tilde{c}_i\, x_i \;+\; C_{\mathrm{fixed}}|P|$$

where \(\tilde{c}_i = \underbrace{U^o + U^r}_{\text{Stage 1: transport}} + \underbrace{\pi_p \cdot \Pr(T_{\mathrm{MF}} > K_i)}_{\text{Stage 2: expected expediting}}\)

Manufacturing slack and recourse:

  • S1 \(K_i = D_p - a_p - T_{\mathrm{LS}} - \mathrm{TT}^o_{j_{\mathrm{out}}} - T_{\mathrm{QC}} - \mathrm{TT}^r_{j_{\mathrm{ret}}}\) — time available for \(T_{\mathrm{MF}}\)
  • S2 If \(T_{\mathrm{MF}} > K_i\): expedite return logistics, saving \(\delta\) days at cost \(\pi_p\) RECOURSE
  • S2 \(\Pr(T_{\mathrm{MF}} > K_i) = 1 - \Phi\!\left(\tfrac{\ln K_i - \mu_L}{\sigma_L}\right)\) — LogNormal survival

Plan filter (hard deadline, even with recourse):

  • \(K_i + \delta \;\ge\; F^{-1}(1-\varepsilon)\) — deadline met even under expediting NEW
  • Plans that cannot meet deadline even with expedited return are excluded

Constraints: identical to deterministic

  • \(\displaystyle\sum_{i\,\in\,\mathrm{Plans}_p} x_i = 1\;\;\forall p\)
  • \(x_i \le z_{m(i)}\;\;\forall i\)    \(\displaystyle\sum_m z_m \le 2\)
  • Capacity: concurrent patients at \(m\) \(\le \mathrm{FCAP}_m\) (using \(F^{-1}(1-\alpha_{\mathrm{cap}})\) as duration)
Same plan structure as deterministic — only the cost and filter threshold change.
No scenarios, no penalty variables, no second-stage subproblems. The stochastic problem reduces to a standard colgen with modified column costs.
Why this reduces to standard column generation: Because the recourse action (expediting) has a known cost \(\pi_p\) and a probability \(\Pr(T_{\mathrm{MF}} > K_i)\) that can be computed analytically from the LogNormal CDF, the expected Stage-2 cost per plan is a closed-form expression. It is simply added to the Stage-1 transport cost to form \(\tilde{c}_i\). The master IP is therefore structurally identical to the deterministic model — same variables, same constraints — with only the column costs modified. No scenario enumeration, no Benders decomposition, no penalty terms.

Solution Algorithm
1
Generate plans: For each patient \(p\) and each route \((m, j_{\mathrm{out}}, j_{\mathrm{ret}})\), compute manufacturing slack \(K_i\) and filter: keep only plans where \(K_i + \delta \ge F^{-1}(1-\varepsilon)\). For kept plans, compute \(\tilde{c}_i = U^o + U^r + \pi_p \cdot \Pr(T_{\mathrm{MF}} > K_i)\).
2
Solve master IP (structurally identical to deterministic): minimise \(\sum_m f_m z_m + \sum_i \tilde{c}_i x_i\) subject to assignment, facility-linking, facility-count, and capacity constraints.
3
Report: For each selected plan, \(\Pr(\text{expediting needed}) = \Pr(T_{\mathrm{MF}} > K_i)\) and expected expediting cost \(= \pi_p \cdot \Pr(T_{\mathrm{MF}} > K_i)\) are recorded. Aggregate service level = fraction of patients with \(\Pr(\text{expediting}) = 0\) (i.e. \(K_i \gg \mathrm{TMFE}\)).
