Parameter Guide

Parameter Value used What it means Effect of increasing
σ_L (sigma_L) 0.2 Spread of manufacturing time T_MF. T_MF ~ LogNormal with this log-scale std deviation. σ_L = 0 means T_MF is always exactly 7 days (deterministic). σ_L = 0.20 means roughly ±20% variation around the mean. More uncertainty → higher P(expedite) → higher expected cost premium over deterministic.
δ (delta) 2.0d Days saved by triggering expedited return shipping. When T_MF > K_i (slack), expediting cuts return transport time by δ days, allowing the patient to still meet their deadline. Larger δ → more routes become feasible under recourse → more plans available → lower cost.
ε (epsilon) 0.05 Plan filter strictness. Only routes where expediting can still rescue the deadline with probability ≥ 1−ε are kept. ε = 0.05 means: even in the worst 5% of T_MF draws, the route must be recoverable. Lower ε → stricter filter → fewer plans → higher cost or infeasibility.
τ (tau) 0.0 Deadline tightness factor (0 to 1). Shrinks patient deadlines to stress-test the model. τ = 0 uses original deadlines (easiest). τ = 1 tightens deadlines to the minimum possible. Higher τ → tighter deadlines → fewer feasible routes → higher cost or infeasibility.
π (pi) H:$8k M:$4k L:$1.5k Cost of triggering expedited return for a High / Medium / Low urgency patient. This enters the objective as E[$exp] = π_p ⋅ P(T_MF > K_i) per patient. Higher π → expediting is more expensive → solver avoids tight routes more aggressively.

Model Design

CCP (Chance-Constrained Programming) replaces the nominal T_MF with an inflated budget T̂_MF = F⁻¹(1−α) so that P(T_MF ≤ T̂_MF) = 1−α. This is a single-stage plan: routes are fixed, and no recourse action is taken if manufacturing runs late. Lower α = stricter guarantee = more conservative routes = higher transport cost.
Two-Stage Expediting ColGen assumes T_MF ~ LogNormal(μ_L, σ_L=0.2). Stage 1 selects a route x_i before T_MF is realised. Stage 2 triggers expedited return (saving δ=2.0d, costing π_p) if T_MF > K_i (slack). Modified column cost: c̃_i = c_transport + π_p ⋅ P(T_MF > K_i). Violations only occur when T_MF > K_i + δ (recourse also fails).
Key difference: CCP commits to a conservative plan upfront (no flexibility). Two-Stage pays a small premium for a recourse action, trading lower up-front cost for the ability to adapt when manufacturing runs long. The out-of-sample tab quantifies this trade-off.

Interpretation

CCP: fixed cost across all scenarios (no recourse). Lower mean cost but higher violation rate when T_MF exceeds the quantile.
Two-Stage: variable cost (transport + realized expediting). Slightly higher mean but near-zero violations — recourse absorbs manufacturing delays.
Key insight: CCP trades lower expected cost for exposure to hard deadline violations. Two-Stage pays a small premium to guarantee a recourse action, virtually eliminating violations.

Key Findings

Average out-of-sample cost gap (Two-Stage vs CCP): -9.4%. Two-Stage pays a small expected-cost premium in exchange for an adaptive recourse action.
Average probability of expediting across all patients and instances: 9.4%. Expediting recourse is rarely triggered, keeping the realized cost premium small.
CCP average violation rate: 51.2% vs Two-Stage: 21.7%. Two-Stage virtually eliminates deadline violations through the expediting recourse action. Monte Carlo validation max error: 41.6% (confirms LogNormal formula).
Scalability: Both solvers scale to N=50 within the time limit. Two-Stage Expediting has a slightly higher plan-generation phase (survival probability computation per column) but the master IP solve time is comparable because the plan count is slightly smaller (tighter feasibility filter K_i ≥ F⊃⁻¹(1−ε) − δ).
When Two-Stage wins: When σ_L is large (high T_MF variability), the deterministic schedule is exposed to deadline violations. Two-Stage pre-prices this risk into the objective, producing schedules that trade a small cost premium for a guaranteed recourse action (expedited return) when manufacturing runs long.

Value of the Stochastic Solution (VSS)

VSS = EEV − RP, where:
• RP (Recourse Problem) = Two-Stage optimal cost (route selection with expediting recourse priced in)
• EEV (Expected value of the Expected Value solution) = deterministic routes evaluated under 10 000 T_MF scenarios with expediting recourse applied post-hoc

A positive VSS means using the stochastic model (Two-Stage) yields a lower expected cost than naively taking the deterministic solution and hoping recourse will cover delays. Average VSS across instances: -12.5%.
