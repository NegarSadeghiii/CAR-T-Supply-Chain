What is Two-Stage Stochastic Programming?

In standard two-stage stochastic programming, decisions are split into two sequential stages separated by the revelation of uncertainty:

Stage 1 — Here-and-Now

Decisions made before $T_{MF}$ is known:
• Which facility to open $z_m$
• Which route (plan) to assign to each patient $x_i$
• These are binary decisions that cannot be changed.

Stage 2 — Wait-and-See (Recourse)

Decisions made after $T_{MF}$ is revealed:
• Observe actual manufacturing duration $\tilde T_{MF,p}$
• Record lateness $y_p = \max(0,\, \widetilde{TRT}_p - D_p)$
• Pay penalty $w_p \cdot y_p$ per day late.

The Key Insight for This Problem

Because $T_{MF}$ enters the total treatment time additively and per-patient, and because each patient is assigned to exactly one plan, the expected second-stage cost separates into a sum over individual plans:

$$\mathbb{E}\!\left[\sum_p w_p\, y_p\right] \;=\; \sum_i x_i \cdot w_{p(i)} \cdot \underbrace{\mathbb{E}\!\left[\max\!\left(0,\; T_{MF} - \text{slack}_i\right)\right]}_{\text{expected lateness for plan } i}$$

This expectation has a closed-form formula for LogNormal $T_{MF}$ (analogous to the Black-Scholes call-option price). No scenarios, no decomposition, no second-stage solver — just a modified column cost.

Result: Column Generation is Fully Preserved

The two-stage stochastic master problem is identical in structure to the deterministic ColGen master — same binary variables, same constraints. Only the cost coefficient of each column changes to include the expected lateness penalty. The column generation subproblem is also unchanged.

How This Differs from CCP

CCP (Chance-Constrained)

• Hard deadline enforcement: $\Pr(TRT_p \le D_p) \ge 1-\alpha$
• Plans that cannot guarantee service level are removed
• Objective unchanged — no lateness term
• Tuned by $\alpha$ (miss-probability budget)
• Binary: plan is feasible or not

Two-Stage Stochastic (this formulation)

• Soft deadline: lateness is allowed but penalised
• All plans remain available
• Objective includes $\mathbb{E}[\text{lateness cost}]$
• Tuned by $w_p$ (penalty weight per urgency group)
• Continuous cost trade-off

Two-Stage Stochastic ColGen — Full Formulation

Uncertainty Model

$$T_{MF} \;\sim\; \text{LogNormal}(\mu_L,\, \sigma_L^2), \quad \mu_L = \ln(\bar T_{MF}) - \tfrac{1}{2}\sigma_L^2, \quad \mathbb{E}[T_{MF}] = \bar T_{MF} = 7 \text{ days}$$

Stage 1 — Master Problem

$$\min_{x,z} \quad \underbrace{\sum_{i \in \mathcal{I}} c_i\, x_i}_{\text{transport cost}} \;+\; \underbrace{\sum_{m \in M} f_m\, z_m}_{\text{facility cost}} \;+\; \underbrace{\sum_{i \in \mathcal{I}} x_i \cdot w_{p(i)} \cdot \mathbb{E}[\max(0,\, T_{MF} - \text{slack}_i)]}_{\text{expected lateness penalty}}$$

where $\text{slack}_i = D_{p(i)} - (T_{LS} + U^o_{c,m,j^{out}} + T_{QC} + U^r_{m,h,j^{ret}})$ is the deadline slack available for manufacturing in plan $i$.

Constraints (unchanged from deterministic ColGen)

$$\sum_{i \in \mathcal{I}_p} x_i = 1 \qquad \forall p \in P \tag{Assign}$$ $$\sum_{m \in M} z_m \le M_{\max} \tag{FacLimit}$$ $$x_i \le z_{m(i)} \qquad \forall i \in \mathcal{I} \tag{FacLink}$$ $$\sum_{i:\, m(i)=m,\, t \in [s_i, s_i+T_{MF})} x_i \;\le\; FCAP_m \qquad \forall m,t \tag{Cap}$$ $$x_i \in \{0,1\},\quad z_m \in \{0,1\} \tag{Binary}$$

Reformulated Objective (absorb expected penalty into column cost)

$$\tilde c_i \;=\; c_i \;+\; w_{p(i)} \cdot \underbrace{\mathbb{E}[\max(0,\, T_{MF} - \text{slack}_i)]}_{\rho(\text{slack}_i,\, \bar T_{MF},\, \sigma_L)} \qquad \Longrightarrow \qquad \min \sum_i \tilde c_i\, x_i + \sum_m f_m z_m$$

The problem structure is identical to deterministic ColGen — only $c_i$ is replaced by $\tilde c_i$.

Analytical Expected Lateness Formula

For $T_{MF} \sim \text{LogNormal}(\mu_L, \sigma_L^2)$ with $\mathbb{E}[T_{MF}] = \bar T_{MF}$, define the slack of plan $i$:

$$K_i \;=\; D_{p(i)} - T_{LS} - TT1_{j^{out}} - T_{QC} - TT3_{j^{ret}}$$

$K_i$ is how much manufacturing time is available before the deadline is breached. The expected lateness is:

Case 1: $K_i \le 0$ (deadline already breached without any manufacturing)

$$\rho(K_i) \;=\; \bar T_{MF} - K_i \qquad \text{(patient is always late)}$$

Case 2: $K_i > 0$ (there is some slack)

$$\rho(K_i) \;=\; \mathbb{E}[\max(0,\, T_{MF} - K_i)] \;=\; \bar T_{MF}\,\Phi(d_1) \;-\; K_i\,\Phi(d_2)$$ $$d_1 = \frac{\mu_L + \sigma_L^2 - \ln K_i}{\sigma_L}, \qquad d_2 = d_1 - \sigma_L, \qquad \Phi = \text{standard normal CDF}$$

Connection to Black-Scholes

This is exactly the Black-Scholes call option formula with:
• "Stock price" $S = \bar T_{MF}$ (mean manufacturing time)
• "Strike price" $K = $ deadline slack
• "Volatility" $\sigma = \sigma_L$, "time" $= 1$, "rate" $r = 0$

Intuitively: the option pays off when $T_{MF}$ exceeds the slack (patient is late). The expected payoff is the expected lateness penalty.

Step-by-Step Calculation

1
Compute $\mu_L$: $\mu_L = \ln(\bar T_{MF}) - \frac{1}{2}\sigma_L^2$. With $\bar T_{MF}=7$, $\sigma_L=0.2$: $\mu_L = \ln 7 - 0.02 = 1.9459 - 0.02 = 1.9259$
2
Compute slack $K_i$ for each plan: $K_i = D_p - T_{LS} - TT1 - T_{QC} - TT3$
3
If $K_i \le 0$: $\rho = \bar T_{MF} - K_i$ (trivially always late)
If $K_i > 0$: compute $d_1$, $d_2$, then $\rho = \bar T_{MF}\cdot\Phi(d_1) - K_i\cdot\Phi(d_2)$
4
Modified column cost: $\tilde c_i = c_i^{\text{transport}} + w_{p(i)} \cdot \rho(K_i)$
5
Solve master IP with $\tilde c_i$ — identical solver, same structure.

Formulation Comparison: Deterministic vs CCP vs Two-Stage

Deterministic ColGen

Objective:
$\min \sum_i c_i x_i + \sum_m f_m z_m$

Plan filter:
$T_{LS}+TT1+\bar T_{MF}+T_{QC}+TT3 \le D_p$

Tuning: none

Guarantee: none under uncertainty

Lateness penalty: none

CCP Stochastic ColGen

Objective:
$\min \sum_i c_i x_i + \sum_m f_m z_m$

Plan filter:
$T_{LS}+TT1+T_{MF}^\alpha+T_{QC}+TT3 \le D_p$
$T_{MF}^\alpha = F^{-1}(1-\alpha)$

Tuning: $\alpha \in (0,1)$

Guarantee: $\Pr(TRT_p \le D_p) \ge 1-\alpha$

Lateness penalty: none

Two-Stage Stochastic ColGen

Objective:
$\min \sum_i \tilde c_i x_i + \sum_m f_m z_m$
$\tilde c_i = c_i + w_p \cdot \rho(K_i)$

Plan filter: none removed

Tuning: $w_p$ per urgency group

Guarantee: minimises expected cost including lateness

Lateness penalty: $w_p \cdot \mathbb{E}[\max(0,T_{MF}-K_i)]$
