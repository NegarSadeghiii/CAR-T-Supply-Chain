2. Hard Deadline Formulation

HARD CONSTRAINT
Minimize total supply chain cost subject to strict on-time delivery — no lateness allowed.
Objective
min Σp Costfacility
  + Σp Costtransport
  + Σp Costmaterial+QC
Pure cost — no penalty term
Key Constraints
TRT[p] ≤ DEADLINE[p] (hard)
Each patient: exactly 1 route
Patient ci returns to hi
Open facilities ≤ MAX_FAC
Patients in mfg at time t ≤ FCAP[m]
Why hard deadlines? CAR-T therapy is time-critical — patient safety is non-negotiable. Soft penalties (Big-M) allowed the solver to trade patient outcomes for cost savings. Hard constraints ensure every patient is treated on time or the model reports infeasibility.

4. Solution Methods

0.00% GAP
Three methods solve the identical hard-deadline problem. Column Generation finds the exact optimal 2,000–6,000x faster than the MIP.
Column Generation (Recommended)
Pre-enumerates feasible patient plans (facility + outbound transport + return transport). Each plan has a known TRT and cost. The solver picks exactly one plan per patient, respecting capacity. ~258 plans for N=15 vs 86,000 MIP variables. Proven optimal, sub-second solve time, scales to N=50.
Benders Decomposition
Master problem selects facilities and assigns patient routes. Subproblem checks if the assigned patients can be scheduled within capacity using CP-SAT interval scheduling. If infeasible, generates a targeted cut and re-solves. Matches ColGen on most cases; slightly suboptimal when transport mode mixing is critical.
Hard Deadline MIP (Reference)
Original time-indexed Pyomo formulation solved with HiGHS. Creates binary variables for every (patient, facility, transport, time) combination. Exact reference for optimality validation. Fails at N≥15 (86,000+ variables, 374,000+ constraints). Used to verify ColGen finds the true optimum.

6. Why Column Generation Works

The MIP creates variables for every (patient, facility, transport, time period) combination. Most are zero in any solution — a patient arriving day 50 doesn't use variables for days 1-49. Column Generation avoids this waste entirely.

Instead of asking "at which time does each patient flow through each stage?" (MIP), ColGen asks: "which route does each patient take?" A route is (facility, outbound transport, return transport). Each patient picks 1 of ~24 routes. Capacity is enforced by checking that overlapping manufacturing windows don't exceed FCAP.

Both formulations define the same feasible region for integer solutions — that's why they find the same optimal (0.00% gap). ColGen just searches the space 2,000-6,000x faster because it has 333x fewer variables.
