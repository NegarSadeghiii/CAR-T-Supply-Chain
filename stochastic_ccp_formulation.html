CAR-T Cell Therapy Supply Chain Optimization MIP vs Column Generation vs Stochastic CCP — Manufacturing Time Uncertainty

Problem: Minimize total cost (facility + transport + material) subject to patient deadlines: $\text{TRT}_p \le D_p$ for all $p$.
Uncertainty: Manufacturing time $T_\text{MF} \sim \text{LogNormal}(\mu_L, \sigma_L^2)$ with $\mathbb{E}[T_\text{MF}]=7$ days.  |  CCP: Route $i$ generated only if $P(\text{TRT}_p \le D_p) \ge 1-\alpha$  |  No penalty terms. Pure cost objective retained.

Side-by-Side Formulation

All three models solve the same underlying CAR-T supply chain problem. The columns below show how each formulation represents decisions, constraints, and uncertainty.

MIP — Time-Indexed

Objective:

$$\min \sum_p \text{CTM}_p + \sum_p \text{TTC}_p + (C_\text{mat}+C_\text{qc})|P|$$

Stage 1 Variables:

  • $E_m \in \{0,1\}$ — open facility $m$
  • $Y^o_{pcmjt} \in \{0,1\}$ — patient $p$ ships from $c$ to $m$ via $j$ at $t$
  • $Y^r_{pmhjt} \in \{0,1\}$ — patient $p$ ships from $m$ to $h$ via $j$ at $t$
  • $\text{INM}_{pmt},\text{OUTM}_{pmt}$ — material flow at $m$
  • $\text{LSA}_{pcmjt},\text{LSR}_{pcmjt}$ — loads shipped / received
  • $\text{OUTC}_{pct},\text{MSO}_{pmhjt},\text{FTD}_{pmhjt}$ — remaining flows

Key Constraints:

  • MSB1: $\text{OUTC}_{pct} = \text{INM}_{pm,t+T_\text{LS}}$ (collection delay)
  • MSB2: $\text{INM}_{pmt} = \text{OUTM}_{pm,t+T_\text{MF}}$ (mfg duration)
  • MSB3–8: transport & QC flow balance
  • CAP1+CAPCON1: $\sum_p \text{INM}_{pmt} \le \text{CAP}_{mt}$
  • Hard deadline: $\text{TRT}_p \le D_p \;\forall p$
  • $\sum_m E_m \le 2$

$T_\text{MF}=7$ hardcoded in MSB2. Uncertainty requires full model rebuild.

Size: $O(|P|\cdot|C|\cdot|M|\cdot|J|\cdot|T|)\approx 86{,}000$ binaries for $N{=}15$

Column Generation — Deterministic

Objective:

$$\min \sum_i c_i\,x_i + \sum_m f_m\,z_m + (C_\text{mat}+C_\text{qc})|P|$$

Variables:

  • $z_m \in \{0,1\}$ — open facility $m$
  • $x_i \in \{0,1\}$ — select plan $i$ for patient $p(i)$
  • Plan $i = (m,\,j_\text{out},\,j_\text{ret},\,w{=}0)$
  • $c_i = U^o_{c(p)\,m\,j_\text{out}} + U^r_{m\,h(p)\,j_\text{ret}}$ — transport cost
  • $f_m = (\text{CIM}_m+\text{CVM}_m)\cdot|T|$ — facility cost
  • $\text{TRT}_i = T_\text{LS}+\text{TT}^o_{j_\text{out}}+T_\text{MF}+T_\text{QC}+\text{TT}^r_{j_\text{ret}}$ (fixed, $T_\text{MF}{=}7$)

Key Constraints:

  • $\displaystyle\sum_{i\in\text{Plans}_p}x_i=1 \;\forall p$ — one plan per patient
  • $x_i \le z_{m(i)} \;\forall i$
  • $\sum_m z_m \le 2$
  • Capacity: $\text{entering}(m,t)-\text{leaving}(m,t)\le\text{FCAP}_m-\text{recent}(m,t)$
    where $\text{mfg\_end}_i = \text{mfg\_start}_i + T_\text{MF}$
  • Deadline filter at generation: plan $i$ created only if $\text{TRT}_i \le D_{p(i)}$

$T_\text{MF}=7$ in both TRT and capacity occupancy. Equivalent to MIP on same feasible region.

Size: $O(|P|\cdot|M|\cdot|J|^2)\approx 258$ plans for $N{=}15$

CCP Stochastic ColGen — Option A

Objective (unchanged):

$$\min \sum_i c_i\,x_i + \sum_m f_m\,z_m + (C_\text{mat}+C_\text{qc})|P|$$

Variables (unchanged):

  • $z_m \in \{0,1\}$ — open facility $m$
  • $x_i \in \{0,1\}$ — select route $i$ for patient $p(i)$
  • Route $i=(m,\,j_\text{out},\,j_\text{ret})$ — no wait, no fixed TRT
  • $c_i = U^o_{c(p)\,m\,j_\text{out}} + U^r_{m\,h(p)\,j_\text{ret}}$ — unchanged
  • $f_m = (\text{CIM}_m+\text{CVM}_m)\cdot|T|$ — unchanged
  • New: $T_\text{MF}\sim F$, $\;\alpha\in(0,1)$, $\;T^\alpha_\text{MF}=F^{-1}(1-\alpha)$

Key Constraints:

  • $\displaystyle\sum_{i\in\text{Routes}_p}x_i=1\;\forall p$ — unchanged
  • $x_i \le z_{m(i)}\;\forall i$ — unchanged
  • $\sum_m z_m \le 2$ — unchanged
  • Capacity: same structure, but $\text{mfg\_end}_i=\text{mfg\_start}_i+T^\alpha_\text{MF}$
  • CCP filter: route $i$ generated only if$$T_\text{LS}+\text{TT}^o_{j_\text{out}}+T^\alpha_\text{MF}+T_\text{QC}+\text{TT}^r_{j_\text{ret}}\le D_{p(i)}$$
  • Guarantee: $P(\text{TRT}_p\le D_p)\ge 1-\alpha\;\forall p$

$T^\alpha_\text{MF}=F^{-1}(1-\alpha)$ replaces $T_\text{MF}{=}7$ everywhere. No penalty terms. No second stage. No scenarios.

Size: same $O(|P|\cdot|M|\cdot|J|^2)$ structure; fewer routes pass filter as $\alpha\downarrow$

Key equivalence: The CCP stochastic formulation is structurally identical to deterministic ColGen. The entire stochastic extension is captured by one substitution: $T_\text{MF}{=}7 \;\ \longrightarrow\;\ T^\alpha_\text{MF} = F^{-1}(1-\alpha)$. The master problem, objective function, facility constraints, and routing constraints are completely unchanged. The parameter $\alpha$ controls the service-level guarantee: routes infeasible at the $(1-\alpha)$-quantile are excluded at generation, not penalized in the objective.

CCP Parameter Design

The CCP Plan-Generation Filter

The chance constraint $P(\text{TRT}_p \le D_p) \ge 1-\alpha$ reduces analytically to a deterministic filter because $T_\text{MF}$ is the only random variable and enters $\text{TRT}_p$ additively: $$P(\text{TRT}_p \le D_p) = P\!\left(T_\text{MF} \le D_p - T_\text{LS} - \text{TT}^o_{j_\text{out}} - T_\text{QC} - \text{TT}^r_{j_\text{ret}}\right) \ge 1-\alpha$$ $$\iff\quad F^{-1}(1-\alpha) \le D_p - T_\text{LS} - \text{TT}^o_{j_\text{out}} - T_\text{QC} - \text{TT}^r_{j_\text{ret}}$$ $$\iff\quad \underbrace{T_\text{LS}+\text{TT}^o_{j_\text{out}}+T^\alpha_\text{MF}+T_\text{QC}+\text{TT}^r_{j_\text{ret}}}_{\text{TRT}^\alpha_i} \le D_{p(i)}$$ This is the same filter as deterministic ColGen, with $T_\text{MF}{=}7$ replaced by $T^\alpha_\text{MF}=F^{-1}(1-\alpha)$.

LogNormal Distribution for $T_\text{MF}$

$T_\text{MF}\sim\text{LogNormal}(\mu_L,\sigma_L^2)$ where $\mu_L = \ln(7)-\tfrac{\sigma_L^2}{2}$ ensures $\mathbb{E}[T_\text{MF}]=7$. The $(1-\alpha)$-quantile is: $T^\alpha_\text{MF} = \exp(\mu_L + z_\alpha\cdot\sigma_L)$ where $z_\alpha=\Phi^{-1}(1-\alpha)$ is the standard normal quantile.

What Changes from Deterministic ColGen to CCP

The CCP extension is a minimal perturbation of cart_colgen.py. The master problem, objective, and all constraint structures are preserved. The only change is the manufacturing time value used in plan generation and capacity occupancy.

Key Findings — Stochastic CCP Extension

1. The CCP extension requires zero structural changes to the master problem. The objective function, routing constraints, facility constraints, and capacity constraint structure are identical to deterministic ColGen. The stochastic extension lives entirely in the plan generation step.
2. No penalty terms, no second stage, no scenarios. The chance constraint $P(\text{TRT}_p\le D_p)\ge 1-\alpha$ reduces to a deterministic filter because $T_\text{MF}$ is additive and scalar per patient. This is exact, not an approximation, for individual (non-joint) chance constraints.
3. Service level $\alpha$ replaces deadline tightness $\tau$ as the primary design parameter. In the deterministic model, $\tau\in[0,1]$ controls how tight deadlines are. In the CCP model, $\alpha\in(0,1)$ controls which quantile of $T_\text{MF}$ is used. Both parameters ultimately control which routes survive plan generation. The CCP model subsumes the deterministic model: setting $\alpha\to 0.50$ with $\sigma_L\to 0$ recovers $T^\alpha_\text{MF}=7$ exactly.
4. High-urgency patients (deadline 18–19d) are most sensitive to $\alpha$. At $\alpha=0.10$ with $\sigma_L=0.3$: $T^\alpha_\text{MF}=10$d. Air/air becomes the only feasible route for high-urgency patients (TRT$^\alpha$=20d). Ground transport is entirely excluded. This is not a modeling artifact — it reflects the real tradeoff: tight deadlines under uncertainty require faster, more expensive transport.
5. Capacity constraint becomes more conservative under CCP. Using $T^\alpha_\text{MF}$ for occupancy duration means each patient's facility slot is reserved for longer. This reduces effective throughput per facility. For high $\sigma_L$, this may force opening a second facility — the same tipping-point behaviour seen at $N{=}20$ in the deterministic sensitivity analysis, but now triggered by uncertainty rather than patient volume.
6. Recommended parameter values for clinical practice. Based on the feasibility table and TRT inflation: $\sigma_L=0.2$ (moderate uncertainty) with $\alpha=0.10$ gives $T^\alpha_\text{MF}\approx 8.9$d — a 1.9-day buffer over nominal. This is a reasonable starting point: 90% of patients meet their deadline, and most routes remain available for medium/low urgency groups.
